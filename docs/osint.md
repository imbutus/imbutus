# osint

Send `osint` in your chat and the model replies with these commands and their exact syntax.

| Command | Subject |
|---|---|
| `osint:email <address>` | One email address. |
| `osint:person <name>` | A person. |
| `osint:company <name>` | A company. |
| `osint:domain <domain>` | A domain. |
| `osint:mentions <text>` | Mentions of a phrase. |
| `osint:phone <number>` | A phone number. |
| `osint:username <handle>` | A username across sites. |
| `osint:instagram <handle>` | An Instagram account. |

Every finding is stored per target on the machine and appears on the machine page.
